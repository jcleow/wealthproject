# Specs Directory Guide

- ai/ — agentic research, implementation guides, and AI scenario PRDs.
- auth/ — authentication specs and security/testing guides.
- backend/ — platform architecture notes plus apd-decimal migration plan/POC.
- financial-modeling/ — allocation/versioning, accumulation, income/interest modeling.
- frontend/ — UI integration notes (e.g., TanStack Query migration).
- growth-pricing/ — growth strategy and pricing/referral plans.
- property/ — property linking and purchase research docs.
- regional/singapore/ — CPF specs, SG finance/tax logic, and car module PRD/tickets.
- scenarios/ — scenario events, subset selector, and scenario-analysis materials.
- timeline/ — timeline performance/flows, monthly resolution, and multiyear planning.
- testing/ — sample data summaries and bug log.
- notes/ — general work notes.
- rewrite-phase-1/, rewrite-phase-2/ — core rewrite specs and tickets.

Other non-Markdown assets (e.g., pricing spreadsheets, cashflow/projection texts) remain in the specs root alongside helper scripts.
